# Prioritized Functional Requirements

## Priority 1 (Hackathon Build)

### Addiction Assessment
1. The system must be able to automatically assess the user's addiction based on their confession entries
2. Users must be able to self-report their addiction severity level

### Confession Entries
1. Users must be able to write entries
2. Users must be able to revisit entries

### Recovery Guidance
1. The system must be able to provide AI-generated advice based on their addiction assessment and recent confessions upon entries

### Recovery Dashboard
1. Users must be able to see their history of confessions
2. Users must be able to see previous guidance

### Content Recommendation
1. The system must be able to provide AI-recommended YouVersion Bible reading plans based on their addiction assessment and recent confessions upon entries
2. The system must be able to provide AI-curated reading plans based on their addiction assessment and recent confessions upon entries
3. The system must be able to provide AI-generated guided prayers based on their addiction assessment and recent confessions upon entries

## Priority 2 (Ring Build)

### Authentication
1. Users must be able to lock their app
2. Users must be able to unlock their app

### Addiction Assessment
1. Users must be able to toggle automatic addiction assessment

### Confession Entries
1. Users must be able to edit entries
2. Users must be able to categorize entries by intensity of temptation
3. Users must be able to categorize entries by location

### Biometric Monitoring
1. The system must be able to record real-time PPG sensor data
2. The system must be able to record real-time EDA sensor data
3. The system must be able to interpret biometric data

### Relapse Intervention
1. The system must be able to model and predict the user's relapse patterns
2. The system must be able to detect elevated risk based on biometric data
3. The system must be able to notify the users when their risk is elevated

### Health Dashboard
1. Users must be able to view their real-time biometric data
2. Users must be able to view biometric interpretations

## Priority 3 (Future Plans)

### Authentication
1. Users must be able to log in
2. Users must be able to sign out
3. Users must be able to create an account
4. Users must be able to delete their account
5. Users must be able to edit their account

### Addiction Assessment
1. Users must be able to take an addiction assessment
2. Users must be able to retake the addiction assessment
3. Users must be able to remove addiction assessment results

### Recovery Guidance
1. Users must be able to rate the guidance that they receive

### Recovery Dashboard
1. The system must be able to provide an AI-summary of a user's recovery journey
2. Users must be able to view their current and historical relapse risk score

### Content Recommendation
1. Users must be able to bookmark AI-generated content

### Biometric Monitoring
1. The system must be able to track sleep
2. The system must be able to analyze HRV

### Relapse Intervention
1. The system must be able to notify their accountability partners when their risk is elevated
2. Users must be able to toggle self notifications
3. Users must be able to toggle incoming partner notifications
4. Users must be able to toggle outgoing partner notifications

### Health Dashboard
1. Users must be able to view their historical sleep data over time
2. Users must be able to view their HRV trends over time

### Accountability Ecosystem
1. Registered users must be able to add accountability partners
2. Registered users must be able to change privacy settings of confession entries
3. Registered users must be able to view accountability partners' visible confession entries
4. Registered users must be able to view public confession entries

### Community
1. Registered users must be able to recommend YouVersion Bible reading plans to other users
2. Users must be able to curate Bible reading plans
3. Registered users must be able to share curated Bible reading plans
4. Registered users must be able to send prayers
5. Users must be able to create guided prayers
6. Registered users must be able to send guided prayers
