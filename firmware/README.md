# Firmware

PlatformIO project for the FellowshipRing wearable device.

## Structure

- `src/` — Firmware source code.
- `include/` — Public headers.
- `lib/` — Private/project-specific libraries.
- `test/` — Unit tests (PlatformIO Unit Testing).
- `platformio.ini` — Project configuration (board, framework, dependencies).
